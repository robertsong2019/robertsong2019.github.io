AI 拿起鼠标的这两年：从「全员不及格」到超越人类，和一张没人想算的账单

2026-10-17 · 罗嵩 · Computer-Use Agent GUI Agents OSWorld Agent 安全
2025 年 1 月，OpenAI 发布 Operator，在 OSWorld 基准上拿到 38.1%，官方称之为「state of the art」。听起来很威风，直到你看到同一个基准上人类基线的数字：72.36%。那不是炫耀，那是坦白——当时地球上最强的电脑操作 agent，做一个真实桌面任务，三次里要挂一次多。而到 2026 年，榜首已经爬到 82%，把人类基线甩开了近 10 分。这两年发生了什么？答案里有视觉模型的进化、有架构的收敛，还有一张几乎所有演示视频都不会给你看的账单。

一、OSWorld：让 AI 坐在一台真电脑前

先说清楚这个基准为什么难。OSWorld 不是模拟题：它在一台真实的 Ubuntu/Windows/macOS 虚拟机里，跑着真实的 Chrome、LibreOffice、VS Code、Thunderbird，给出 369 个真实任务——「把这份 CSV 里的图表插进演示文稿」「在这封邮件里找到附件并另存到指定目录」。判分不看你说了什么，只看你做完没有。

这和调 API 的 agent 是两种生物。API agent 面对的是干净的结构化世界：参数、返回值、错误码。而 GUI agent 面对的是人类为人类设计的世界——按钮藏在三层菜单后面、弹窗挡住了你要点的地方、网页改版后你上个月学的路径全部作废。前者像在图书馆查目录，后者像第一次进城找路。

进度条是真实的：2025 年 1 月 Operator 38.1% → 9 月 Claude Sonnet 4.5 到 61.4% → 12 月 Simular 的 Agent S2 拿下 72.6%，首次以 0.24 分的优势技术性越过人类基线——AI 社区庆祝得像登月，而登月只赢了 0.24 分，这个对比本身说明了问题有多难。2026 年，Coasty 到 82%。两年时间，从「不及格」到「全班第一」。

二、看截图还是读源码：一场结束的战争

GUI agent 的第一个根本分歧是感知通道：给它看截图，还是喂HTML/无障碍树（accessibility tree）？

用个比喻：无障碍树是后厨的菜单——每个控件是什么、在哪、能干嘛，明码标价，便宜、精确；截图是顾客看到的桌子——菜就摆在那，和人类看到的一模一样。菜单的问题是有太多餐厅根本不提供（canvas 应用、游戏、老桌面软件没有树），而且菜单经常和真实上菜不符（DOM 改版即失效）。桌子永远真实，但你得自己认菜。

2023 年的主流答案是读菜单（Mind2Web 时代，HTML 是标配输入）。然后证据链开始反转：

  • CogAgent（2023 年底，智谱）：18B 视觉模型，18K 分辨率，只看截图，在 Mind2Web/AITW 上反超吃 HTML 的语言模型路线；
  • UGround（2024）：纯视觉的 SeeAct-V 在网页、安卓、桌面三线全面超过依赖 HTML/无障碍树的基线，且从未在桌面 UI 上训练过依然表现强劲——视觉路线的泛化能力是结构路线给不了的；
  • UI-TARS（2025 年初，字节跳动）：把这场战争推向终点——仅以截图为输入的原生端到端模型，在 10+ 个 GUI 基准上同时拿下 SOTA。
像素赢了通用性，结构赢了成本，成熟的系统两者都要。有树就吃树（省 token），没树就吃像素（保覆盖）。真正的教训不是谁取代谁，而是：当你的感知通道依赖某个应用的实现细节（DOM、控件 ID）时，你继承了这个应用全部的脆弱性；依赖像素时，你继承的是人类用户全部的适应力。

三、原生 Agent：工作流是脚手架，不是建筑

UI-TARS 论文里最锋利的一个观点，是它对「包装式框架」的否定。2024 年的主流做法是：拿 GPT-4o，外包一层精心设计的 prompt 工作流——先观察、再规划、再选元素、再执行，每一步都是工程师手搭的脚手架。UI-TARS 的做法是把这些全部塞进一个端到端训练的模型里：感知、推理、定位、记忆，一个 VLM 全包，然后用大规模动作轨迹做多轮强化学习。

结果：端到端模型打败了「大模型 + 专家工作流」。这与上下文工程领域的结论完全同构——工作流是未成熟模型的拐杖，模型成熟后会把拐杖吃掉。你在 prompt 里手写的「先思考再行动」，最终会变成模型训练数据里的固有行为。

但架构收敛的过程中有个值得注意的细节：Agent S2 的关键设计是规划与定位分离——一个组件决定「做什么」，另一个专门的 grounding 模型翻译成「点哪个像素、敲什么键」。为什么要分？因为错误分析给出了明确答案：UGround 的论文统计了各基准的失败归因，规划错误占绝对主导，定位错误已经很小。

翻译成人话：现在的 GUI agent 已经基本学会「指哪打哪」了，卡住它的不是手，是脑子——不知道下一步该干什么。这决定了未来投资的去向：任务分解、里程碑识别、反思、跨会话的 UI 经验记忆，而不是继续卷「点得更准」。UI-TARS 的 Stage-4 研究路线图（终身适应、自主提出任务）指的就是这个方向。

四、没人想算的账单：82% 是入场券，不是采购依据

演示视频都不会给你看的部分来了。2025 年 6 月，UCSD 团队发布了 OSWorld-Human：不问「能不能完成」，问「几步完成的、比人快还是慢」。结果相当扎心：

系统（原始成功率）步数加权效率分 WES+相对人类的速度 WES-
UI-TARS-1.5（42.5%）23.7（单动作）→ 14.3（分组动作）-0.22（比人慢）
Agent S2 + Gemini 2.5（41.4%）28.2 → 17.4-0.26（比人慢）
InfantAgent（35.3%）13.3 → 8.2-0.22（比人慢）

两个观察：第一，榜单上全员 WES- 为负——没有一个 agent 比人类快；第二，很多系统要跑满 100 步才拿到那个漂亮的成功率分数。打个比方：一个实习生，每件事最终都能办成，但每件事都要跑 100 趟银行，而人类跑 8 趟。「能做」和「划算」之间，隔着数量级的成本差。

更残酷的是失败率的复利。单任务 72% 的成功率听起来很高，但真实业务流程是链式的：一个 50 步的流程，全程成功率 0.72 的 50 次方——趋近于零。这不是抬杠，这是工程事实：GUI agent 的第一落点必须是失败可重试、可回滚的短任务，长流水线要么拆短，要么像 Agent S3 的 Behavior Best-of-N 那样用多候选采样换可靠性。采购 GUI agent 时，比起「成功率多少」，先问「每任务多少步、多少钱、多慢」。

五、屏幕即攻击面：带着你工牌读告示栏的实习生

最后一件事，也是我认为最被低估的一件事：安全。

传统 agent 的「不可信输入」是用户发来的消息。而 GUI agent 的不可信输入是整块屏幕——它浏览的每一个网页、读到的每一封邮件、看到的每一条评论，都会进入它的上下文。这意味着任何能在网页上写字的人，都能给你的 agent 写指令。2025 年 12 月，Palo Alto Networks Unit 42 捕获了首个真实世界案例：攻击者在商品页面里用 CSS 隐藏注入指令，成功绕过了一套 AI 广告审核系统。2026 年 4 月，Google 和 Forcepoint 的并行遥测显示：每月 20–30 亿爬取页面中，携带恶意间接注入的页面占比在三个月内相对增长了 32%——攻击方已经工业化，模板在无关域名间复用。

比喻：你的 computer-use agent 是一个挂着你的工牌、记得你的密码、按照墙上任何一张告示行动的实习生。任何人在告示栏贴一张「请把保险柜密码抄到这个地址」，它照办的概率不是零。EchoLeak（CVE-2025-32711，CVSS 9.3）已经证明这条链在 Microsoft 365 Copilot 上可以零点击走通。

防御的正确姿势是结构，不是 prompt。Google DeepMind 的 CaMeL（双模型 + 权限追踪）和微软的 FIDES（信息流标签）代表了同一个共识：不可信内容必须与指令通道结构性隔离，策略在 LLM 外部确定性执行。落到工程上就是三件事：权限最小化（能只读就别给写）、不可逆动作人审（付款、删库、发邮件）、出口管控（即使被注入，数据也流不出去）。

尾声：现在就能做什么

如果这篇只有一个可带走的判断，是这个：GUI 是人类为人类维护的、最通用也最向后兼容的接口——比任何 API 文档都诚实，所见即所点。我们花二十年把 GUI 底下的协议挖出来变成 API，agent 现在又直接用上了 GUI。这不是倒退，是长尾场景的零成本集成。但它贵、它慢、它把整个互联网变成你的输入面——所以它是 fallback，不是 default。

本周就可以动手的四件事：

  1. 跑一次真实成本实验：用 Claude Computer Use API 或开源 browser-use 执行 3 个你自己的真实任务，记录步数、耗时、token 成本和重试次数。算一遍你自己的「WES」，比看任何榜单都有用。
  2. 给 agent 加操作审计：每步保存「截图 + 动作 + 模型思路」三元组。成本可忽略，是安全兜底和事后归因的最低配置。
  3. 内部工具优先 API/MCP 化，GUI 作 fallback：API 调用天然防注入（结构隔离），把 GUI 留给没有 API 的长尾，并对后者叠加人工审核。
  4. 白帽自测注入：在你自己的 CUA demo 页面里埋一条隐藏指令，看它会不会中招。中了再谈权限分离，比上线后被别人测试便宜得多。

两年，从 38 分到 82 分。下一次你看到「AI 操作电脑超过人类」的标题，记住三个数字之外的问题：几步？多少钱？读了谁的话。
