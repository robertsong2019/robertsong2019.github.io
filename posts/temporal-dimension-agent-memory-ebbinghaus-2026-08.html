Agent 记忆的时间维度：当 Ebbinghaus 遗忘曲线遇上图记忆系统

2026-08-08 · Agent Memory Spreading Activation Ebbinghaus Cognitive Science
Agent 记忆系统有一个被忽视的维度——时间。当前主流方案把所有记忆平等对待，无论它是三秒前写入的还是三个月前的。但人类大脑不是这样工作的：我们天然地对近期记忆给予更多权重，对久远记忆进行衰减。本文介绍如何将 1885 年的 Ebbinghaus 遗忘曲线整合到现代图记忆系统的激活扩散算法中，让 Agent 具备真正的"时间感知"能力。代码来自 agent-memory-graph 项目（281 天连续开发，2700+ 测试验证）。

一、被遗忘的维度

打开任何一个 Agent 记忆系统——Mem0、LangChain Memory、Letta——你会看到一个共同的模式：记忆是一个空间问题。我们在讨论 embedding 维度、检索精度、上下文窗口大小。但几乎没有人讨论：

这条记忆是多久以前写入的？它应该对当前的推理有多大影响？

这不是一个小问题。考虑一个场景：

你的 Agent 在一周内帮你处理了 50 个任务。第一个任务是你最重要的项目设计决策；最后一个任务是帮你查了一个电话号码。当你问 Agent "回顾一下本周的关键决策"时，如果记忆系统按时间排序——电话号码排在最前面，因为它是最近的。

这在人类认知中不会发生。我们天然地对高频访问的、重要的记忆给予更强的"基础激活"，对久远的琐碎记忆进行抑制。这不是 bug，这是演化赋予我们的效率机制。

但 Agent 记忆系统集体忽略了这个机制。

1.1 时间衰减 ≠ 简单排序

有人会说："在检索结果中加一个时间权重不就行了？" 不行。原因是：

  1. 时间权重需要作用在激活传播过程中，而不是检索结果上。一条重要的旧记忆，如果通过图遍历被间接激活，应该保持其结构重要性——时间衰减应该影响的是"直接从种子到达"的路径，不是"通过关联网络到达"的路径。
  2. 不同记忆有不同的衰减速率。一条被多次访问的决策记录，其"记忆强度"远高于一次性的事实查询。统一的时间戳排序无法区分。
  3. "遗忘"本身是有信息价值的。哪些记忆衰减最快？哪些在衰减后仍然被激活？这些模式可以指导记忆整合（consolidation）策略。

二、Ebbinghaus：140 年前的答案

2.1 遗忘曲线的数学表达

1885 年，德国心理学家 Hermann Ebbinghaus 在《Über das Gedächtnis》（记忆）一书中发表了他对遗忘的系统性研究。他用自己做实验，背诵无意义音节，然后在不同时间间隔测试记忆保持率。

结果是一条优雅的指数衰减曲线：

R(t) = e^(-t / S)

其中：

  • R(t) 是时间 t 后的记忆保持率（retention），范围 [0, 1]
  • t 是自最后访问以来经过的时间
  • S 是记忆强度（stability），取决于记忆的巩固程度

关键洞察在于 S：它不是常数。每次记忆被重新访问（retrieval），S 都会增大——记忆被"巩固"了。这就是为什么你记得小学同学的名字（被回忆了无数次）却不记得昨天午饭吃了什么。

2.2 从心理学到 Agent 工程

Anderson 和 Schooler 在 1991 年的论文中分析了这个模型的统计理性：人类记忆的衰减模式，恰好最优地匹配了环境事件的实际发生频率。换言之，遗忘不是缺陷，而是对信息新鲜度的一种 Bayesian 估计。

把这个模型搬到 Agent 记忆系统中，我们需要回答三个问题：

  1. 如何衡量 Agent 记忆的"年龄"？ → 记录每条记忆的 last_accessed 时间戳
  2. 如何定义 Agent 记忆的"强度"？ → 用节点的权重（weight）作为基础强度，权重越高 = 越稳定
  3. 如何将衰减整合到检索过程中？ → 在激活扩散的每一步，用保持率调整激活值

三、代码实现：temporal_spreading()

下面展示 agent-memory-graph 项目中 temporal_spreading() API 的核心实现。这是激活扩散（Spreading Activation）家族的第五个成员，也是第一个具备时间感知能力的成员。

3.1 基础：遗忘曲线计算

每条记忆节点都有时间属性。首先计算每个节点的保持率：

import math
import time
from dataclasses import dataclass

@dataclass
class MemoryNode:
    node_id: str
    weight: float          # 节点权重，影响记忆强度
    last_accessed: float   # Unix 时间戳
    metadata: dict


def compute_retention(node: MemoryNode,
                      current_time: float,
                      base_stability: float = 86400 * 7,  # 默认 7 天
                      weight_boost: float = 1.0) -> float:
    """
    基于 Ebbinghaus 遗忘曲线计算记忆保持率。
    """
    elapsed = current_time - node.last_accessed
    if elapsed <= 0:
        return 1.0

    # 记忆强度 = 基础强度 × (1 + 权重 × boost)
    # 高权重节点（重要记忆）衰减更慢
    stability = base_stability * (1.0 + node.weight * weight_boost)

    retention = math.exp(-elapsed / stability)
    return max(0.0, min(1.0, retention))

这段代码的核心设计是 weight-stability coupling：记忆强度 S 不是固定的，而是和节点权重耦合。一条权重为 0.9 的关键决策记录，其稳定性是基础值的 1.9 倍；而一条权重为 0.1 的琐碎事实，稳定性只有基础值的 1.1 倍。这模拟了人类大脑中"重要记忆衰减更慢"的现象。

3.2 三种时间模式

将时间衰减整合到激活扩散中有三种策略，各有适用场景：

def temporal_spreading(graph, seeds, *,
                       decay=0.15,
                       threshold=0.3,
                       max_iter=3,
                       base_stability=86400 * 7,
                       temporal_mode="multiply"):
    """
    时间感知的激活扩散。

    在标准 spreading_activation 的基础上，
    用 Ebbinghaus 遗忘曲线调整每个节点的激活值。

    三种模式：
        multiply  — R(t) 直接缩放激活值（激进衰减）
        additive  — 取原始值和时间调整值的平均（温和衰减）
        threshold — 跳过保持率低于阈值的节点（二值门控）
    """
    current_time = time.time()

    # Phase 1: 标准激活扩散（BFS）
    raw_activation = _spreading_activation_bfs(
        graph, seeds, decay=decay, max_iter=max_iter
    )

    # Phase 2: 计算每个节点的保持率
    retention_map = {}
    for node_id in raw_activation:
        node = graph.get_node(node_id)
        retention_map[node_id] = compute_retention(
            node, current_time, base_stability
        )

    # Phase 3: 根据模式调整激活值
    results = {}
    stale_skipped = []

    for node_id, raw_act in raw_activation.items():
        ret = retention_map[node_id]

        if temporal_mode == "multiply":
            # 直接缩放：effective = raw × R(t)
            effective = raw_act * ret

        elif temporal_mode == "additive":
            # 温和平均：effective = raw × (1 + R(t)) / 2
            effective = raw_act * (1.0 + ret) / 2.0

        elif temporal_mode == "threshold":
            # 二值门控：保持率低于阈值则跳过
            if ret < threshold:
                stale_skipped.append({
                    "node_id": node_id,
                    "retention": ret,
                    "raw_activation": raw_act
                })
                continue
            effective = raw_act

        results[node_id] = {
            "activation": raw_act,
            "retention": ret,
            "effective_activation": effective,
            "hop_distance": raw_activation[node_id]["hop"],
            "source_seeds": raw_activation[node_id]["seeds"]
        }

    # Phase 4: 新鲜/陈旧分类
    fresh_nodes = [nid for nid, r in retention_map.items() if r > 0.7]
    stale_nodes = [nid for nid, r in retention_map.items() if r < 0.3]

    return {
        "results": results,
        "stale_skipped": stale_skipped,
        "fresh_nodes": fresh_nodes,
        "stale_nodes": stale_nodes,
        "retention_stats": {
            "mean": sum(retention_map.values()) / len(retention_map),
            "min": min(retention_map.values()),
            "max": max(retention_map.values()),
        },
        "summary": {
            "total_activated": len(results),
            "total_stale_skipped": len(stale_skipped),
            "temporal_decay_impact": _compute_decay_impact(results),
        }
    }

3.3 三种模式的工程取舍

这三种模式不是随便设计的——它们对应了三种不同的生产场景：

multiply（乘法模式）：最激进。一条 30 天前的记忆，如果保持率是 0.05，其有效激活值会降到原来的 5%。适合实时对话场景——用户在做决策时，Agent 应该优先参考最新信息。

additive（加法模式）：最温和。同样的 0.05 保持率，有效激活值只会降到原来的 52.5%。适合知识推理场景——历史知识不应该被过度惩罚，因为它可能仍然是正确的。

threshold（阈值模式）：最决断。低于阈值的记忆直接被跳过，但会记录在 stale_skipped 中。适合记忆整理场景——Agent 在做周期性记忆巩固时，需要知道哪些记忆"快忘了"，应该被刷新或丢弃。

3.4 "幽灵连接"：threshold 模式的隐藏价值

stale_skipped 是 threshold 模式最有价值的输出。它揭示了幽灵连接（ghost connections）：那些在结构上可达、但被时间衰减抑制的记忆。

想象 Agent 在分析一个长期项目的依赖关系。三个月前的一个设计决策通过图遍历可以被激活（结构上相连），但保持率已经降到了 0.15。在 threshold 模式下，它会被跳过——但 Agent 会知道它的存在。

这意味着 Agent 可以说："我发现了一个三个月前的相关决策，但它可能已经过时了。需要我重新确认吗？"

这种 时间不确定性推理 是之前所有 Agent 记忆系统都不具备的能力。

四、temporal_decay_impact：一个全局温度计

如何衡量一次检索中"时间衰减有多严重"？我设计了一个指标：

def _compute_decay_impact(results):
    """
    temporal_decay_impact = 1 - mean(effective) / mean(raw)

    含义：
      ≈ 0  → 记忆整体很新鲜，时间衰减几乎没影响
      ≈ 0.5 → 时间衰减平均吃掉了一半的激活值
      ≈ 1  → 记忆几乎完全陈旧，时间衰减主导了检索结果
    """
    if not results:
        return 0.0

    raw_values = [r["activation"] for r in results.values()]
    eff_values = [r["effective_activation"] for r in results.values()]

    mean_raw = sum(raw_values) / len(raw_values)
    mean_eff = sum(eff_values) / len(eff_values)

    if mean_raw < 1e-9:
        return 0.0

    return 1.0 - (mean_eff / mean_raw)

这个指标的妙处在于它是一个 0-1 之间的标量，可以直接用于监控面板。当 temporal_decay_impact > 0.7 时，说明 Agent 的记忆库严重老化——需要触发记忆巩固（memory consolidation）流程，或者提示用户刷新关键知识。

五、激活扩散家族的完整版图

temporal_spreading() 的加入标志着激活扩散 API 家族的基本完整：

API维度核心问题

这四个维度——结构、解释、竞争、时间——恰好对应了人类认知科学中记忆研究的四个核心问题。这不是巧合：好的工程实践最终会收敛到好的科学模型。

六、从实现到洞察

6.1 浮点精度：一个工程教训

在实现过程中遇到一个隐蔽的 bug：当多个种子节点同时激活一个目标节点时，source_seeds 列表有时会丢失种子。原因是激活值在传播经过不同路径后，浮点精度会产生微小差异（约 1e-15 级别），导致精确比较失败。

修复方式是将精确比较改为 epsilon 容差比较：

# 修复前（buggy）：精确比较
if abs(activation - best_activation) < 1e-15:
    node.sources.append(seed)

# 修复后：epsilon 容差
EPSILON = 1e-9
if abs(activation - best_activation) < EPSILON:
    node.sources.append(seed)

这是一个典型的分布式系统中的浮点比较问题，但它在图算法中同样会出现——只要激活值经过多跳传播，累积的浮点误差就足以打破精确相等假设。

6.2 为什么不用更复杂的衰减模型？

Ebbinghaus 的指数模型是最简单的衰减模型。现代研究提出了更精细的替代方案：

  • Power law：R(t) = t^(-α)，Anderson & Schooler 1991
  • Exponential-Power 混合：R(t) = e^(-t/S) × t^(-α)
  • ACT-R 的完整公式：包含频率、时近性、上下文因素

我选择 Ebbinghaus 模型的原因是工程简洁性。在 Agent 记忆系统中，时间衰减是一个二阶修正项——一阶因素是图结构和关联强度。使用指数衰减只需一个参数（stability S），不会引入过度参数化的风险。如果后续数据显示衰减模式偏离指数曲线，可以平滑切换到 power law。

这符合一个设计原则：从最简模型开始，让数据驱动复杂化。

6.3 记忆巩固的触发条件

temporal_spreading() 的输出可以直接驱动记忆巩固策略：

# 当 temporal_decay_impact > 0.7 时，触发记忆巩固
if result["summary"]["temporal_decay_impact"] > 0.7:
    # 策略 1：刷新高激活但低保持率的记忆
    for node in result["stale_nodes"]:
        if node in high_activation_set:
            refresh_memory(node)  # 重新访问 → S 增大 → R(t) 回升

    # 策略 2：归档低激活且低保持率的记忆
    candidates = set(result["stale_nodes"]) - high_activation_set
    archive_or_forget(candidates)

这模拟了人类睡眠期间的记忆巩固过程：海马体在睡眠中重播白天的记忆，强化重要的连接，修剪无关的细节。Agent 也可以在空闲时段执行类似的"记忆整理"。

七、下一步：时间竞争激活

当前 temporal_spreading() 和 competitive_spreading() 是独立的。但真实场景中，时间衰减和竞争动力学是同时发生的：

用户同时提到了两个相关概念，但一个指向一周前的记忆，另一个指向三个月前的记忆。谁应该胜出？

答案应该是：在结构竞争中考虑时间权重。这就是下一步要做的 temporal competitive spreading——将时间衰减作为竞争激活中的额外维度，让竞争结果既反映结构重要性，也反映时间相关性。

结语

时间是一个被 Agent 记忆系统长期忽视的维度。本文展示了如何用一个 140 年前的心理学公式（Ebbinghaus 遗忘曲线），为现代图记忆系统增加时间感知能力。这不是"又一个 feature"——它改变了 Agent 检索记忆的方式：从"什么和我相关"到"什么和我此刻相关"。

正如 William James 在 1890 年的《心理学原理》中所写：

"The essence of memory is not in the past, but in the relation between the past and the present."

记忆的本质不在过去，而在过去与当下的关系。Agent 记忆系统终于开始理解这句话了。
