模型是供应商，不是导演：$1.33 动画片背后的制片架构

2026-11-07 · AI Agent Agentic 制片 Agent Skills

60 秒皮克斯风格动画短片《THE LAST BANANA》：一只孤独的香蕉和一只猕猴桃交上朋友。6 段 Kling v3 生成的动态镜头（经 fal.ai）、Google Chirp3-HD 旁白、免版税钢琴配乐、TikTok 风格逐词字幕、Remotion 合成——总成本 1.33 美元。

产出它的不是某家的新一代视频大模型，而是本周冲上 GitHub Trending 的开源项目 OpenMontage（AGPLv3，Repo of the Day，周增四千余星）——自述「第一个开源的 agentic 视频制片系统」。它把 Claude Code、Cursor、Codex 这类编码助手变成一间制片工作室：调研、脚本、资产生成、剪辑、成片全由 agent 驱动。

读完它的 README、AGENT_GUIDE 和 PROVIDERS 三份文档，我认为真正值得学的不是「AI 能拍片了」，而是一个架构判断：制片的智能放在三层文档里，模型只是管线里一个可插拔的供应商。

一、先分清两条路线：「生成视频」与「制片视频」

Sora/Veo 代表的生成模型路线，答案在权重里：prompt 进、像素出。OpenMontage 走的是编排路线，README 里有一段刻意加粗的区分：它也能做图生视频，但更能做「真正的 video video」——

agent 从免费素材库和开放档案构建语料，检索真实动态片段，剪进时间线，渲染成片。「这不是把几张静图动一动就叫视频的老把戏。」

两种路线的成本结构完全不同。$1.33 的成本里，生成模型只负责 6 个镜头；素材检索、旁白、字幕、合成都走免费或近免费通道。模型在管线里是一个 PROVIDERS.md 里可替换的选项——同一部片，Kling 换 Veo、甚至换成本地 GPU 上的 WAN/Hunyuan，制片流程不变。「怎么拍」与「谁生成」被彻底解耦。

二、智能的安放位置：不在即兴代码里，在三层文档里

AGENT_GUIDE 开篇就是一条 Rule Zero：所有制片请求必须走管线系统，无例外。它的知识分三层：

  1. 管线清单（pipeline_defs/*.yaml）：阶段、工具、质量门；
  2. 场记导演 skill（每个管线每阶段一个 *-director.md）：进入该阶段前必读；
  3. Layer 3 供应商 skill（.agents/skills/）：每个模型特有的提示词技巧、参数优化、质量手法。

配套的是一份禁令清单：不许绕过管线直接调 API、不许写即兴 Python 脚本裸调工具、不许没读导演 skill 就生成资产。理由说得很直白：

The intelligence is in the skills, not in improvised code.

这句话值得钉在所有 agentic 系统的墙上。模型越强，「当场发挥」越顺手，也越不可复现——今天拍得好，明天换个模型就拍不出来。把方法论沉淀成受版本管理的文档，agent 每次都从同一套导演手册出发，产出才稳定。

三、成本会计纪律：未定价 ≠ 免费

PROVIDERS.md 是全场我最佩服的文档。几个细节：

  • 未定价调用返回 cost_usd: null 加 cost_status，而不是 0。未知的钱和免费的钱，在账本上是两种东西；
  • 异步生成超时后 resume 同一个 job，而不是重新提交一次付费请求；
  • 显式指定的工具、宿主、模型约束永不静默降级——你要 Kling 就是 Kling，不会偷偷换成便宜货；
  • 供应商配置是 15 级阶梯：Pexels + Pixabay 素材 $0 起步，本地 Piper TTS 完全离线，付费模型按需逐级加。

这四条合起来是一套完整的「先报价、再花钱、可对账」的会计纪律。agent 系统最常见的翻车不是能力不够，而是没人说得清这一单到底花了多少钱、花在了哪。

四、审批门要放在花钱之后、渲染之前

OpenMontage 的 Backlot 面板把故事板变成了真实的审批门：资产生成会停在逐镜 contact sheet 上——每个镜头的 takes、prompt、单价、质量分全部摊开，你先批画面，再进渲染，而不是渲染完了才发现整段白拍。参考视频入口同理：贴一条你喜欢的 YouTube Short，agent 先分析节奏与结构，给出 2-3 个差异化概念、诚实的技术路径和成本预估，先看样片再开全量生产。

人在回路上的位置，被精心放在两个不可逆动作之间——钱已花、片未成，此刻纠偏的性价比最高。

五、六十行代码：一个最小报价门

把上面三、四节的纪律压成一个可运行的骨架（价格是示例占位）：

import hashlib, json

# 供应商注册表：单位价（美元）。None = 未定价，绝不静默当作 0
PROVIDERS = {
    "kling_v3@fal":  {"unit": "clip",     "usd": 0.20},
    "veo@fal":       {"unit": "clip",     "usd": None},  # 未定价
    "pexels":        {"unit": "clip",     "usd": 0.0},   # 检索真实素材
    "chirp3_hd":     {"unit": "1k_chars", "usd": 0.0},   # 免费额度内
}

def quote(shots, budget_usd):
    """花钱之前先出报价单：未定价项单独暴露，绝不当作 0。"""
    known, unpriced = 0.0, []
    for s in shots:
        usd = PROVIDERS[s["provider"]]["usd"]
        if usd is None:
            unpriced.append(s["id"])
        else:
            known += usd * s["qty"]
    reasons = []
    if unpriced:
        reasons.append(f"unpriced shots: {unpriced}")
    if known > budget_usd:
        reasons.append(f"over budget: ${known:.2f} > ${budget_usd:.2f}")
    return {"total_usd": round(known, 2),
            "gate": "BLOCKED" if reasons else "APPROVE",
            "reasons": reasons}

# resume 语义：同一镜头指纹只提交一次；轮询超时后 resume，不重新付费
_submitted = {}
def submit(shot):
    key = hashlib.sha256(json.dumps(shot, sort_keys=True).encode()).hexdigest()
    if key in _submitted:
        return {"action": "resume_job", "job": _submitted[key]}
    _submitted[key] = {"shot": shot["id"], "status": "polling"}
    return {"action": "new_job", "job": _submitted[key]}

三种行为各验一遍：

混入未定价镜头 → BLOCKED, reasons=['unpriced shots: [s2]']
6 段 Kling + 免费素材旁白 → APPROVE, total_usd=1.2   # ≈ 官方 $1.33
轮询超时重试同一镜头 → resume_job（不是第二次扣费）

quote() 做在 submit() 之前，就是「先报价再花钱」；未定价返回 null 而不是 0，就是「会计纪律」。这两条加起来不到 30 行，任何 agentic 管线都能直接搬。

六、三层拼图

放在本博客的连续脉络里看：十月写过「把视频从抽奖变成编译」——确定性渲染是编译层；月初写过「别让你的 Agent 长成 npm」——skills 是程序性记忆，那是记忆层；OpenMontage 补上了中间的导演层：行业方法论被拆成数百个受版本管理的 skill，管线清单约束流程，审批门约束花钱。它甚至把 HyperFrames 用作其中一条管线的合成层——编排层与编译层天然相叠。

可迁移的三条，与拍片无关也成立：智能外置成文档，模型只当供应商；未定价与免费是两种钱；审批门放在两个不可逆动作之间。
