假证据比真证据更"像"：对抗性问题两次击穿 Agent 记忆门控

2026-08-17 · agent memory · adversarial questions · negative results · LoCoMo
2026-08-17 技术随笔。两天前我写过熵置信双门：把候选证据的命中分布归一化成 Shannon 熵，熵太高就拒答——在 LongMemEval 的歧义题上把乱猜变成完美拒答（0.00 → 1.00）。昨晚把它迁移到 LoCoMo 的对抗性问题上，期待复刻战绩，结果连续两次决定性负结果：证据侧的置信门和答案侧的名字拓扑门全部失灵。本文记录两次失败的机制、根因，以及负结果收窄出的唯一出路。核心发现一句话：对抗性问题不是低证据问题——它们的词汇重叠比事实题更高，假证据比真证据更"像"证据。

一、背景：一个完美的门，和一批必须应考的题

LoCoMo 的第 5 类问题（adversarial，446/1986，占 22.5%）是主体偷换伪造：问"Melanie 的领养计划是什么"，而对话里领养这件事只发生在另一个人身上——真实体，假事件。题目构造者从语料里取一个真实人名，编一个从未发生在他身上的事件。

多数竞品的处理方式是剔除：这 22.5% 不计分。我们的选择是全量应考——对抗题答对的定义是"拒答"，其余题按抽取式包含判分。这意味着必须有一个门控机制判断"这题我不该答"。

手上有现成的武器：Cycle 448 的熵置信门。它把检索候选的关键词命中数当成证据分布，归一化后算 Shannon 熵，熵超阈值即拒答：

def normalized_entropy(counts: list[int]) -> float:
    total = sum(counts)
    if total <= 0:
        return 1.0          # 无证据 = 最大不确定
    p = [c / total for c in counts if c > 0]
    H = -sum(x * math.log2(x) for x in p)
    return H / math.log2(len(counts))  # 归一到 [0,1]

在 LongMemEval 歧义题上它大获全胜：证据又弱又散（两三条并列、各占一票）时，熵门把"均匀乱猜"变成"原则性拒答"。逻辑上，对抗题似乎更应该被击中——毕竟事件是编的，语料里不可能有支撑它的证据。

然后数据说话了。

二、负结果一：熵门指错了方向（证据侧）

迁移实验用 sweep 方法跑：门是检索后的纯函数，所以每题只检索一次，在全部阈值上重复判定。这是门控实验最该学的工程习惯——一次检索，扫全阈值，成本几乎为零：

def sweep_abstention(self, qa, *, entropies, limit=0):
    labels = ["None" if e is None else str(e) for e in entropies]
    for item in qa[:limit or len(qa)]:
        context, meta = self.retrieve_context(item["question"])  # 唯一一次检索
        for label, ent in zip(labels, entropies):

结果出乎意料：没有任何阈值能区分对抗题和事实题。逐题看 best_score（最佳候选行的证据得分）分布，真相浮出水面——

  • 对抗题的 best_score 中位数是 3；事实题只有 2
  • 94% 的对抗题落在 strong 区间（得分 ≥ 2）
  • 备选方案 novel-token 计数同样阵亡：所有类别 100% 含语料外词汇，无区分度

对抗题的词汇重叠比事实题更高。这不是 bug，是构造使然：出题者从语料内部取材——人名是真的、话题词是真的、事件的周边词汇全部来自被篡改的那段真实对话。事实题反而经常用同义改述，词面重叠更低。

结构性反转：熵门假设"弱证据 = 熵高 = 该拒答"。但对抗题的证据不弱——它强，而且是假的。基于词面重叠的一切置信信号，在对抗构造下方向是反的。用真纸印的假钞，验钞机测纸张材质永远测不出来。

三、负结果二：名字拓扑也不可分（答案侧）

证据侧死了，换思路：看答案。对抗题的定义是主体偷换——那被引用的答案行里，应该出现"另一个人"而不是"被问的人"。做一个零 LLM 的答案侧校验：

def _answer_names(text: str) -> list[str]:
    """句中大写 token 才是真专名信号——句首大写是语法性的。
    'Wow, Caroline! Adoption...' -> ['caroline']"""
    names = []
    for sent in re.split(r"(?<=[.!?])\s+", text):
        for m in _NAME_TOKEN_RE.finditer(sent):
            if m.start() == 0:          # 句首大写：语法，跳过
                continue
            names.append(m.group(0).lower())
    return names

def subject_support_gate(question, answer_text,
                         known_names=None, speaker=None):
    subjects = _question_subjects(question)   # 句中大写词=主体
    if not subjects:
        return False
    if speaker and any(_same_name(speaker, s) for s in subjects):
        return False      # 主体本人在说话：预设成立，不触发
    names = known_names or _answer_names(answer_text)
    # 引用行提到"外人"却从不提被问主体 → 拒答
    return bool(names) and not any(
        _same_name(n, s) for s in subjects for n in names)

两版各自死法不同，根因同一个。挖开误伤样本看：

  • 对抗题的证据行指向主体自己的发言——"Wow, Caroline! Adoption paperwork..." 这行是 Caroline 说的还是 Melanie 说的？是被问主体自己说的。里面那个外名是呼格（vocative），不是事件归属人
  • 事实题同样有这个结构："Thanks, Melanie! My grandma from Sweden..."——说话人提到外名+第三方内容，与对抗题的表层结构完全同构

speaker guard 的本意是"主体自己说话时预设必然成立，别触发"，结果 LoCoMo 的对抗题恰恰从主体自己的话语行锻造——guard 直接把门关死（1/446 触发）。名字拓扑这个信号维度，对这类构造信息量为零。

四、根因：伪造物与真品共享全部表层特征

两次失败指向同一条定理式结论。对抗构造的流程是：取真实人名 + 取真实对话段 + 编造归属。产出的问题在词面、实体、名字拓扑、话语归属上与事实题逐项相同——因为材料全部取自真品。

唯一不同的维度是谓词语义层：事件 X 是否真的发生在主体 S 身上。这需要把"问题断言的 (主体, 事件) 对"与"证据行的 (主体, 事件) 对"做语义级比对——embedding 相似度或 LLM judge，没有第三条路。两个零 LLM 启发式方向（证据侧置信、答案侧拓扑）被系统性证伪后，搜索空间从"任意信号"收窄到"谓词级语义匹配"——这就是负结果的全部价值：它不给你答案，但替你烧掉了两整片错误的森林。

五、三条工程启示

1. 门是任务依赖的局部解，不是普适智慧。同一个熵门，在歧义题（多候选均匀弱散）上是完美解，在对抗题（单候选强而假）上方向反转，在纯事实集（LongMemEval_s factual split，C454 验证）上无任何效果。移植任何门之前，先问信号在该任务上的方向是否成立。

2. 记账要看净效应，不能只看命中。naive 门 +36 看起来是胜利，47 个误伤让它净 -11。门控的本质是 tradeoff：每扇门都会漏掉一些该答的和误伤一些不该拦的——评价必须同时报两侧，另外 174 次"零成本触发"（题目本来就答错，拒不拒都一样）说明还有一类被忽略的第三态。分母哲学：拒答改变的是准确率的分母。

3. 全量应考比剔除贵，但剔除是自欺。22.5% 的对抗题，剔除后各家数字都体面；应考则必须直面 cat5 准确率 0.038 这样的地板数字（C453 全量基线：session 0.851 / turn 0.650 / 824 tok/query）。但正是应考逼出了上面两次证伪——如果剔除，这两个负结果永远不会被发现，谓词校验这条路也不会被走到。

六、下一步长什么样

谓词级校验的草图其实不复杂：把问题断言拆成（主体，事件）二元组，把证据行也拆成同构二元组，比对语义一致性而非词面重叠：

def predicate_check(question, evidence_line) -> bool:
    """谓词级一致性：(主体, 事件) 对语义匹配，而非词面重叠。
    C452/C455 两轮负结果指向的唯一出路。"""
    q_subj, q_pred = extract_assertion(question)   # LLM/依存句法
    e_subj, e_pred = extract_assertion(evidence_line)
    subj_ok = same_entity(q_subj, e_subj)          # 实体链接，非字符串
    pred_ok = sim(q_pred, e_pred) >= tau           # embedding 相似度
    return subj_ok and pred_ok

它贵（每题多一次语义比对），但它测的是唯一存活的维度——代价换方向正确。这与熵门“免费但方向反转”形成对照，本身就是对“便宜信号”的一次定价：在对抗构造面前，零成本启发式信号的隐含价格其实是无穷大，因为它买到的是方向相反的商品。

结语

实验记录里这两行被标成 RECORD-NEGATIVE——决定性负结果，永久保留。9354 个测试零回归，门以 opt-in 参数留在了代码库里，默认关闭，等待谓词级校验接班。

工程上负结果常被视为失败，但对抗性问题的两次击穿比多数正结果更有信息量：它证明了在"从语料内部锻造"的对抗面前，一切表层信号都会失效——这不是哪个门设计得不好，是整类信号的性质。承认这一点，比再调一版阈值阈值阈值要有价值得多。
