01 · Overview

架构演进分水岭：两代之间

表格中的方案属于车企公开规划的下一代量产架构路线图，多数尚未大规模落地； 当前市面主流仍是「多域控制器架构」，仅少量车型小规模搭载中央超算 + 区控硬件。

当前主流量产

多域控制器架构（存量主流）

  • ●座舱域 / 智驾域 / 动力域 / 车身域相互独立的域控制器
  • ●分布式网关，各域之间需编/解码中转
  • ●ECU 数量多、线束重、软件迭代慢
  • ●代表：小鹏 X-EEA3.5 / 蔚来 NT2.9 / 理想 LEEA2.0 / 广汽星灵3.0 / 吉利 GEEA3.0 / 大众 MEB
下一代目标架构

中央超算 + 区域控制器

  • ●舱驾控一体 HPC 内置网关，算力集中到单一中央单元
  • ●取消分散独立网关 / 域控，消除数据中转节点
  • ●区域控制器就近 I/O 采集与执行，线束轻量化
  • ●代表：小鹏 X-EEA4.0 / 蔚来 NT3.0 / 理想 LEEA3.0 / 广汽星灵4.0 / 吉利 GEEA4.0 / 大众 CEA1.0

关键结论：HPC 内置集成网关、将座舱 + 智驾 + 整车网关算力收敛到单一中央单元，是当前「中央 + 区控」路线下兼顾性能与硬件成本的行业公认最优解 —— 这一底层判断没有过时。

05 · Industry Trend

行业演进 时间线与共识

存量主流

多域控制器架构

座舱/智驾/动力/车身独立域控 + 分布式网关

过渡 · 2024-2025

准中央融合 / 双 HPC 松耦合

大众 CEA 1.0 量产；多数「舱驾一体」实为逻辑融合、硬件分离

目标 · 2026-2028

中央超算 + 区域控制规模化

单芯片舱驾一体（高通 8775/8797、英伟达 Thor）集中上车

终局 · 2028+

单芯全域融合 + 端侧大模型

小鹏 VLMU 独立大模型硬件先行布局端侧生成式 AI

🧠

中央 HPC 集成网关

座舱 + 智驾 + 整车网关收敛到单一中央单元，取消独立网关与各类独立域控，消除数据中转节点。

🌐

TSN 车载以太网成标准

作为主干网络成为行业共识；分歧仅在 1G / 2.5G / 10G 的带宽选择。

⚙️

区域控制器 + I/O 路线博弈

带 I/O Box 可轻量化线束但增加接插件成本；区控直驱负载则反之，两种路线均有 OEM 论证支撑。

工程现实修正

"纸面规划" vs "工程落地" 的三处差距

① 舱驾一体 HPC 落地难

纸面写「舱驾控 + GW」，量产阶段多采用舱计算 + 智驾计算松耦合，逻辑融合先行、硬件单体融合滞后。

② 10G TSN 成本与供给瓶颈

成熟低成本车载 10G 以太网芯片选择有限，部分新车先预留接口、初期跑 2.5G、后期 OTA 开放万兆。

③ I/O Box 路线博弈

小鹏/蔚来/理想/广汽采用独立 I/O Box；吉利/上汽/长安/长城/比亚迪/大众区控直驱负载。无绝对对错，取决于整车成本模型。

06 · Domestic Divergence

国内主机厂 路线分化解读

补充上汽 / 长安 / 长城 / 比亚迪后，国内阵营呈现三类典型路线：中央计算形态分化、量产节奏分化、自研模式分化。

分化一 · 中央计算形态

单 HPC vs 双 HPC vs 多计算平台

  • 单 HPC小鹏/蔚来/理想/广汽/比亚迪 → 终极目标
  • 双 HPC上汽零束独有（HPC1+HPC2 容错/扩展）
  • 三平台长城 GEEP4.0（中央/智驾/座舱分离过渡）

→ 多计算平台属过渡形态，最终收敛到单 HPC 全域融合。

分化二 · 量产节奏

已规模化 vs 规划中

  • 已落地比亚迪璇玑覆盖仰望/腾势/王朝/海洋；零跑四叶草 C10/C16 量产；小鹏 G7 X-EEA4.0 装车
  • 2025落地上汽零束全栈3.0四域合一；长安 SDA 启源A06首发
  • 规划中蔚来NT3.0 / 理想LEEA3.0 / 广汽星灵4.0 / 长城GEEP4.0

→ 比亚迪、零跑在量产进度上领先，依托全栈/全域自研与性价比策略。

分化三 · 自研模式

全栈自研 vs 子公司 vs 合作

  • 全栈自研比亚迪（硬件+OS+算法）/ 小鹏 / 蔚来 / 理想 / 零跑
  • 子公司上汽零束、吉利内部供应商模式
  • 自研主导长安 SDA、长城 GEEP（自主架构定义）
  • 联合开发大众 CEA × 小鹏（唯一海外合作案例）

→ 国内 10 家均走自研/子公司路线，仅大众依赖外部合作。

🔍 五家新补充车企关键看点

上汽零束 · 全栈 3.0/4.0

唯一双 HPC 架构（HPC1+HPC2），理念为"计算+通信"；3.0 实现"舱驾算联"四域合一并支持 L3；4.0 升级 AI OS + 智能体协同，面向 AI 原生车。→ 走"多 HPC 容错"而非"单 HPC 极致集中"的差异化路线。

长安 · SDA 天枢架构

2021 年启动，独创6 层架构（机械/能量/EEA/OS/应用/云端）；软硬解耦 + 服务化 SOA；智驾走纯视觉路线（去传感器绑定、去高精地图）；启源 A06 首发，规划 7 款新车。→ 架构分层理念最清晰，软件驱动（Super DNA）。

长城 · GEEP 4.0

采用三大计算平台（中央/智驾/座舱）+ 3 个区域控制器 VIU，属"准中央"过渡形态；中央计算 SOC 30 KDMIPS，率先整合车身/网关/动力底盘/ADAS；配套线控底盘五大系统（转向/制动/换挡/油门/悬挂）+ SOA 开放 API。→ 线控底盘能力突出，但中央融合程度落后单 HPC 阵营。

比亚迪 · 璇玑架构 Xuanji

行业首个整车一体融合方案，"一脑两端三网四链"设计；中央超算"天璇" + "天玑"冗余备份；双千兆双以太网环网；全栈自研（硬件/OS/算法）；已规模化覆盖仰望/腾势/王朝/海洋四大矩阵。→ 表中少数已大规模量产的架构，凭借垂直整合领先落地。

零跑 · LEAP 3.0 四叶草

用 1 SOC + 1 MCU 双芯构建中央超算实现"四域合一"（座舱/智驾/动力/车身），中央超算集成 15 个功能模块；ECU 由 42 减至 28、线束由 1850m 减至 1500m；业界首个整车无感 OTA；C10/C16 已量产。→ 以更少芯片实现高集成度，"价格屠夫"式性价比路线。

07 · Bottom Line

一句话总结

这份架构对标符合各家车企对外官宣的下一代技术规划（2026–2028 量产目标）， 适用于战略研讨与竞品分析；但当前绝大多数车型仍跑在上一代多域控制器 EEA 上。 行业底层判断 ——中央 HPC 集成网关、走向中央计算 + 区域控制器—— 没有过时，是公认演进方向。

中央 HPC 集成网关 = 性能/成本最优解 小鹏 VLMU = 端侧大模型先行者 比亚迪璇玑 = 已规模化量产领先者 零跑四叶草 = 双芯四域高性价比 上汽零束 = 双 HPC 差异化路线 大众 = 保守过渡路线
