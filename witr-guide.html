// 02 · 核心

四个问题，一命令答完

witr 把所有东西都当"进程问题"——端口、服务、容器、命令最终都映射到 PID。一旦锁定 PID，它就构建一条因果链。

01
What is running?
进程的可执行文件、PID、用户、命令行、启动时间、重启次数。
02
How did it start?
完整祖先链：systemd → sshd → bash → pm2 → node，看得见每一步。
03
What keeps it alive?
谁在 supervise 它？systemd unit / launchd / docker / pm2 / cron / SSH session。
04
What context?
cwd、git 分支、容器名、监听地址、capabilities、健康警告。

// 04 · 速查

Flags 完整参考

所有 target flags 都可重复、可混搭：witr nginx --port 5432 --pid 1234

Flag作用
-p, --pid <ids>按 PID 查（可重复）
-o, --port <ports>按端口号查
-f, --file <paths>查谁打开了某文件
-c, --container <names>按容器名/镜像/compose 查
-x, --exact精确匹配（关闭模糊）
-s, --short单行祖先链 · 脚本最爱
-t, --tree树形祖先链（含子进程）
--jsonJSON 输出 · 接监控用
--env输出进程环境变量
--warnings只输出告警（root / 公网监听 / LD_PRELOAD 等）
--verbose容器 mounts / networks / compose 元数据
-i, --interactive进入 TUI（4 Tab：进程 / 端口 / 容器 / 锁）
--no-color关色（CI / pipe）
-v, --version版本
// 05 · 自动化

退出码 · 让 witr 进 CI

每个码都有明确含义，case $? 一接就能用。

0
Clean
进程找到，无告警
1
Warnings
找到但含告警（root / 公网）
2
Not Found
无匹配进程
3
Permission Denied
权限不足，需 sudo
4
Invalid Input
参数错误或多匹配歧义
5
Internal Error
witr 自身异常
CI 监控脚本
$ witr nginx --short $ case $? in 0) echo "All clear" ;; 1) alert_team "witr: nginx has warnings" ;; 2) alert_team "witr: nginx NOT running" ;; 3) echo "Need sudo" ;; esac
// 06 · 安全

witr 会替你察觉的"危险信号"

这些告警会让 exit code 变 1，立刻可用于安全合规扫描。

⚠ 01
以 root 运行
非系统进程不该长期 root。
⚠ 02
危险 capabilities
非 root 进程却带 CAP_SYS_ADMIN 等。
⚠ 03
公网监听
绑定 0.0.0.0 / :: 而非 127.0.0.1。
⚠ 04
重启多次
超阈值的 restart count。
⚠ 05
吃内存
RSS > 1GB 的进程。
⚠ 06
跑了 90 天+
长期未重启，可能漏补丁。
⚠ 07
二进制已删
进程还在跑，但 /proc/<pid>/exe 失效。
⚠ 08
注入痕迹
LD_PRELOAD / DYLD_* 环境变量。
// 07 · TUI

交互模式 · 四个 Tab

直接 witr 或 witr -i 进入。鼠标可点、自适应刷新（3 秒起，负载高时退避）。

Processes
进程 Tab
实时可排序可过滤的进程列表 + 右侧祖先树。支持 KILL / TERM / PAUSE / RESUME / RENICE（Unix）。
Ports
端口 Tab
所有 LISTEN 端口 + 持有进程。按 a 切换 LISTEN-only / ALL。
Containers
容器 Tab
跨 Docker / Podman / nerdctl / K8s / Incus / LXC / LXD / jails 统一视图。
Locks
文件锁 Tab
POSIX/FLOCK 锁 + 所有打开的 fd。按 / 搜索。

平台原生实现亮点

witr 不调用 PowerShell / WMI / Python，每端都是原生 API。

Linux
/proc 全功能
capabilities、systemd unit、cgroups、snap/flatpak 沙箱、systemd timer 全识别。
macOS
ps + lsof + launchctl

Windows
ToolHelp32 / PSAPI / SCM

FreeBSD
procstat + ps + lsof
