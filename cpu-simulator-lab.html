Abstraction Layers

“模拟芯片”其实分很多层

不同工具回答的问题不一样。QEMU 重在软件能不能跑，Ripes 重在教学可视化，Verilator 重在 RTL 是否真的按周期执行，SystemC/gem5 重在系统级架构探索。

01功能级模拟QEMU、Spike。快速跑程序、跑系统，但一般不细看每个周期的硬件内部。
02教学流水线Ripes、WebRISC-V。可视化指令如何经过 IF/ID/EX/MEM/WB。
03RTL 仿真Verilator、Icarus、商业仿真器。真正跑 Verilog/SystemVerilog 设计。
04系统级建模SystemC/TLM、gem5。用更高抽象层模拟 CPU、总线、内存和外设交互。
05全栈教学Nand2Tetris。从 NAND 门、CPU、汇编器、编译器一路到程序。
Hello World Path

一段 C 程序到 CPU 输出，实际经历了什么

最经典的教学实验是让 `hello.c` 最后通过 memory-mapped UART 打印字符。这样你能同时看到软件、指令、内存、总线、外设和波形。

hello.c你写的 C 代码，里面调用 puts 或直接写 UART 地址。
riscv-gcc交叉编译成 RISC-V ELF，包含指令、数据和入口地址。
objcopy把 ELF 转成 hex/bin，加载到仿真内存。
CPU fetchPC 指向第一条指令，CPU 从内存取指。
pipeline指令经过译码、执行、访存、写回。
UART write程序写一个特殊地址，仿真器把它当成串口输出。
terminal屏幕打印 hello，同时可用 GTKWave 看每根信号。
Open Source Projects

这些开源项目可以拼出完整学习体验

没有一个工具能完美覆盖所有层次。最实用的方法是组合使用：先用可视化工具建立直觉，再用真实 RTL 仿真建立工程感。

Ripes

最适合课堂演示 RISC-V 流水线。可以看到寄存器、内存、指令执行和流水线状态。

  • 适合：计算机组成、体系结构入门
  • 重点：流水线、冒险、指令执行

Nand2Tetris

从 NAND 门一路构造计算机、汇编器、VM、编译器和 OS。它不是 RISC-V，但教学闭环极完整。

  • 适合：理解计算机底层全貌
  • 重点：从门电路到软件栈

PicoRV32 / Ibex

真实开源 RISC-V CPU RTL。配合 Verilator，可以跑固件、看波形、理解 RTL CPU 的行为。

  • 适合：数字前端、RTL 入门
  • 重点：真实硬件描述语言

QEMU / Spike

功能级模拟器，适合快速跑 RISC-V/ARM 程序或系统，验证软件栈和 ISA 行为。

  • 适合：固件、OS、编译工具链
  • 重点：程序是否能正确运行

Renode

面向嵌入式和 SoC 的虚拟平台，可以模拟外设、板卡、传感器和多节点系统。

  • 适合：嵌入式软件和 SoC 平台
  • 重点：系统级外设交互

gem5 / SystemC

用于体系结构和系统级建模。比 RTL 抽象，适合研究缓存、内存、互连、时序和架构取舍。

  • 适合：架构研究、性能建模
  • 重点：系统级探索而非门级细节
Recommended Route

最适合学生的实践路线

你的目标如果是“看见 hello world 怎么在处理器里执行”，可以按下面顺序走。每一步都能形成一个可展示的小项目。

路线 A：先建立直觉

  • 用 Nand2Tetris 理解门电路、ALU、寄存器、CPU、汇编器。
  • 用 Ripes 跑 RISC-V 小程序，看指令如何走流水线。
  • 写几个汇编例子：加法、循环、函数调用、内存访问。

路线 B：进入真实 RTL

  • 选 PicoRV32 或 Ibex。
  • 用 riscv-gcc 编译 hello.c，生成 memory image。
  • 用 Verilator 跑 CPU RTL，通过 UART 打印字符。
  • 用 GTKWave 看 PC、寄存器写回、总线访问和 UART 信号。
最好的展示不是“我知道 QEMU”，而是把同一个 hello world 放进三种显微镜里看：QEMU 看它能跑，Ripes 看它怎么过流水线，Verilator 看真实 RTL 信号怎么跳。 这正好连接计算机组成、编译器、嵌入式、数字前端和验证，是非常适合学生的跨层项目。
Tool Choice

不同工具适合回答不同问题

选工具前先问自己：我是要跑软件、看流水线、验证 RTL，还是研究系统架构？

工具/项目 抽象层级 最适合展示 不擅长什么
QEMU / Spike ISA / 功能级 程序能否在目标架构上运行，固件和 OS 是否启动。 不适合展示每个周期的真实硬件内部信号。
Ripes 教学微架构 RISC-V 指令、寄存器、内存、流水线和冒险处理。 不是量产 CPU RTL，也不是后端物理实现。
Verilator + RTL CPU 周期级 RTL 真实 Verilog/SystemVerilog CPU 怎么执行程序。 跑大型 OS 和复杂外设会比 QEMU 慢很多。
SystemC / gem5 系统级 / 架构级 缓存、内存、互连、时序和系统架构探索。 不直接等同于最终门级电路。
Nand2Tetris 全栈教学 从门电路到 CPU、汇编器、编译器和 OS 的完整闭环。 不是工业 RISC-V/ARM 架构。
